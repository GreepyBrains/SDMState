# State Pattern
Das State Pattern (Zustandsmuster) ist ein Verhaltensmuster in der Softwareentwicklung. 
Es ermöglicht einem Objekt, sein Verhalten komplett zu ändern, wenn sich sein interner Zustand ändert. 
Statt unübersichtlicher if-else- oder switch-Blöcke wird jeder Zustand in eine eigene Klasse ausgelagert.

## Aufgabe)
Wandel die gegebene Klasse so um, dass man das Statepattern anwenden kann.

## Aufgabe Einfach)
Die Grundstruktur für das Statepattern ist schon gegeben. 
Deine Aufgabe besteht darin, den Code innerhalb der Interfaces zu ergänzen.
